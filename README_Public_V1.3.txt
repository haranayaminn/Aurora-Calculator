■ 公開方法
1. ZIPを展開します。
2. index.html / script.js / style.css を同じフォルダーに置きます。
3. GitHubへ反映し、Cloudflare Pagesへ再デプロイします（Git連携の場合はpush後に自動デプロイ）。
4. PCとスマートフォンの両方で表示を確認してください。

※広告の実配信状況はこの環境から確認していません。広告ブロッカー、配信審査、広告枠設定、通信環境等により表示されない場合があります。
