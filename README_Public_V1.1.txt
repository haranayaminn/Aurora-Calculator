■ V1.2 変更内容
・既存の電卓・ツール機能は維持しています。
・左側に1つ目の忍者AdMax広告を配置しました。
・右側に2つ目の忍者AdMax広告を追加しました。
・メイン画面の下側に3つ目の忍者AdMax広告を追加しました。
・PC（画面幅1101px以上）は左右に広告を固定表示します。
・画面幅1100px以下では左右の広告を隠し、下側広告のみ表示して画面幅を確保します。
・広告の配信サイズはAdMax側の広告枠設定に従います。CSSで広告自体のサイズを変更するものではありません。

■ 公開方法
1. ZIPを展開します。
2. 展開した index.html / script.js / style.css を同じフォルダーに置きます。
3. NetlifyまたはCloudflare Pagesへ再デプロイします。
4. PCとスマートフォンの両方で表示を確認してください。

※広告の実配信状況はこの環境から確認していません。広告ブロッカー、配信審査、広告枠の設定、通信環境等により表示されない場合があります。
