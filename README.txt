Aurora Calculator - AdMax 非同期・左側1枠版

内容
- 直前の「左側1枠版」をベースにしています。
- 広告は左側に1枠だけ設置しています（スマートフォンなど幅900px以下ではメイン画面の上に移動します）。
- AdMaxの広告タグは、指定された公式の非同期タグに差し替えています。
- 広告IDは 16b8082440abbf054772880ab50e84da のみです。
- 計算機本体の script.js は変更していません。

ファイル
- index.html
- style.css
- script.js

設置方法
1. ZIPを展開します。
2. 3ファイルを同じフォルダーに置いたまま、公開先へアップロードします。
3. 既存の公開ファイルを置き換えてデプロイします。

確認事項
- この版では、広告タグの読み込みを async にしています。広告スクリプトの読み込み待ちでページ本体が止まりにくくなることを狙った変更です。
- ただし、広告そのものが表示されるまでの時間はAdMax側の配信状況、通信環境、広告ブロック機能などにも左右されるため、表示遅延の解消を保証するものではありません。
- 公開後は広告ブロック機能を無効にした通常の環境でも表示を確認してください。
- 広告リクエストの重複を避けるため、タグを手動で追加したり、同じ枠を複数回読み込ませたりしないでください。
