Aurora Calculator - AdMax 1枠テスト版

内容
- 元のAurora CalculatorのHTML/CSS/JavaScriptをベースにしています。
- 広告はページ下部に1枠だけ設置しています。
- 使用している広告タグは今回指定された新しいNinja AdMaxタグのみです。
- 以前の広告IDは含めていません。
- script.jsの計算機能部分は変更していません。

ファイル
- index.html
- style.css
- script.js

確認事項
1. 3ファイルを同じフォルダーに置いてください。
2. index.htmlを開いてレイアウトを確認してください。
3. AdMaxの広告配信は、タグを設置しただけでは保証されません。
   公開環境で広告枠の状態、配信状況、広告ブロック機能などを確認してください。
4. この版では広告枠を1つだけにして、表示確認しやすくしています。
