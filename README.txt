Aurora Calculator - AdMaxコード表示修正版（左側1枠）

今回の修正
- 広告枠は左側に1つだけ設置しています。
- HTML内からAdMaxのJavaScriptコードを取り除き、広告枠のdivだけを残しました。
- AdMaxのキュー登録と t.js の読み込みを script.js 内で実行する方式に変更しました。
- ローダーは非同期（async）で読み込み、同一ページでの二重初期化を防止します。
- 使用する広告IDは 16b8082440abbf054772880ab50e84da のみです。
- 電卓の既存機能・スタイルは、広告関連以外は元ファイルを維持しています。

ファイル
- index.html
- style.css
- script.js

Cloudflareへの反映手順
1. ZIPを展開します。
2. 3ファイル（index.html / style.css / script.js）をGitHubリポジトリの公開ルートへ配置し、既存ファイルを置き換えます。
3. GitHubへコミット・プッシュし、Cloudflareのビルドが成功したことを確認します。
4. Cloudflareの「訪問する」から公開ページを開き、Ctrl+F5で再読み込みします。

重要
- この修正版では、広告コードそのものをHTML本文として表示する経路を避けるため、JavaScriptを外部の script.js に移しています。
- 広告が実際に配信・表示されるか、また表示までの時間はAdMax側の配信状況、通信環境、広告ブロック機能などにも左右されます。表示や収益を保証するものではありません。
- 既存のHTMLへ広告タグを追加で貼り付けないでください。広告枠やローダーの重複は避けてください。
- デプロイ後もコードが文字で表示される場合は、Cloudflareが古いビルドを配信している可能性があるため、GitHubの最新コミットとCloudflareの成功した最新デプロイを確認してください。
