Aurora Calculator Public Edition V1.0
====================================

This is the public-release build based on the supplied latest Aurora calculator files dated 2026-10-31.

Files
-----
- index.html
- style.css
- script.js

Removed completely from the public edition
------------------------------------------
- 学習・問題
- レポート・研究
- 自動化・モデル
- 連携・ライブラリ
- 画像解析

Retained
--------
- Existing calculator and scientific calculation features
- Formula and numeric databases
- Graphing, data visualization, quick tools, experiment/3D tools
- User guide and settings
- Quick Tools local memos
- Accessibility settings
- Existing main backup/restore, with workspace backup narrowed to retained memos and accessibility settings

Compatibility notes
-------------------
- Existing legacy workspace data for removed features is ignored by this public build.
- The quick-tools local memo data and accessibility preferences are retained.
- Older backups may contain removed-category data; the public build deliberately does not restore those removed categories.
- The original uploaded files are not modified. This folder is a separate public-release copy.

Run locally
-----------
Keep the three files in the same folder and open index.html in a modern browser.
