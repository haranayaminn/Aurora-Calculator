Aurora Calculator - AdMax 再読み込み対策版（左側1枠）

今回の修正
- AdMax初期化を独立した admax-loader.js に分離しました。
- index.html では広告枠のコンテナだけを保持し、読み込み処理は独立ファイルで実行します。
- admax-loader.js は script.js より前に defer で読み込まれます。
- AdMaxの公式キュー形式と https://adm.shinobi.jp/st/t.js を使用します。
- 広告リクエストを自動で繰り返さない設計にし、重複リクエストを避けます。
- 計算履歴を読み込む際にデータ形式を検証し、不正な要素を除外・修復して保存し直します。
- バックアップ復元時の履歴も同じ方法で検証します。
- 履歴の保存キーや通常の電卓機能は変更していません。

ファイル
- index.html
- style.css
- script.js
- admax-loader.js

公開手順
1. ZIPを展開します。
2. 4ファイルすべてを同じ公開フォルダーへ配置してください。
3. GitHub連携の場合は4ファイルをリポジトリの同じ階層で置き換えてコミット・プッシュします。
4. Cloudflareの新しいデプロイが成功したことを確認してから公開ページを再読み込みします。

注意
- これは読み込み処理の独立化と履歴データの安全化です。AdMax側が広告素材を返さない場合や、ネットワーク・ブラウザー側が通信を遮断した場合の表示を保証するものではありません。
- 自動リトライや広告枠の連続再読み込みは行いません。
- ブラウザーでの実広告配信テストは未実施です。公開後、DevToolsのNetworkで t.js の状態を確認してください。
