Aurora Calculator - AdMax 再読み込み対策版 v2（左側1枠）

今回の改善
- 広告枠を160×600pxで最初から確保し、読み込み中もページのレイアウトが大きく動かないようにしました。
- 読み込み中は「広告を読み込み中…」を表示します。
- AdMaxが広告要素（表示可能なiframe・画像等）を挿入したことを検出したら案内を隠します。
- 30秒以内に広告要素を検出できない場合は「広告を取得できませんでした」と表示します。
- 30秒を過ぎて広告が遅れて届いた場合も、検出できれば案内を隠します。
- 広告リクエストの自動再試行・連続再読み込みは行いません。
- 広告処理は admax-loader.js に分離し、電卓本体の script.js から独立させています。
- script.js と admax-loader.js にバージョン付きURLを付け、古いキャッシュを読み続けにくくしました。
- 既存の履歴データ検証・修復処理と電卓機能を維持しています。

公開手順
1. ZIPを展開します。
2. 5ファイルすべてを同じ公開フォルダーへ配置します。
3. GitHub連携の場合は5ファイルをリポジトリの同じ階層で置き換えてコミット・プッシュします。
4. Cloudflareの新しいデプロイが成功したことを確認します。
5. 公開ページを Ctrl+F5 で再読み込みします。

注意
- 広告の表示そのものはAdMax側の配信状況、広告素材の応答、通信環境、ブラウザー設定に依存します。
- 30秒の表示は案内文を切り替えるためのもので、広告リクエストの再送信は行いません。
- 広告のDOM構造はAdMax側で変更されることがあるため、実配信表示の最終確認は公開環境で行ってください。
- 「document.domain mutation is ignored because the surrounding agent cluster is origin-keyed」は document.domain の旧式なドメイン共有設定が無視された警告です。これ単独で広告表示の失敗を示すものではありません。
